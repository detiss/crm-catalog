# CRM-Каталог — агрегатор українських CRM-систем

Односторінковий сайт для порівняння CRM-систем: таблиця з характеристиками, теги, плюси й мінуси, фільтри, порівняння до 4 систем.

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS

## Запуск локально

Потрібен [Node.js](https://nodejs.org) версії 20 або новіше.

```bash
npm install
npm run dev
```
