# CRM-Каталог — агрегатор українських CRM-систем

Односторінковий сайт для порівняння CRM-систем: таблиця з характеристиками, теги, плюси й мінуси, фільтри, порівняння до 4 систем.

**Стек:** React 19 · TypeScript · Vite · Tailwind CSS. Бекенду немає — усі дані лежать у `src/data/crms.ts`.

## Запуск локально

Потрібен [Node.js](https://nodejs.org) версії 20 або новіше.

```bash
npm install
npm run dev
```

Сайт відкриється на http://localhost:3000.

Зібрати продакшн-версію та переглянути її:

```bash
npm run build
npm run preview
```

## Публікація на GitHub Pages

1. Створіть публічний репозиторій на github.com та завантажте в нього вміст цієї папки (разом з `.github`).
2. У репозиторії: **Settings → Pages → Source → GitHub Actions**.
3. Після push у гілку `main` сайт збереться автоматично; адреса: `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Як додати або змінити CRM

Відкрийте `src/data/crms.ts` і додайте новий об'єкт у масив `CRMS` за зразком наявних. Теги та сегменти для фільтрів задаються у списках `SEGMENTS` і `FEATURE_TAGS` у цьому ж файлі.

## Структура

```
src/data/crms.ts          — дані всіх CRM
src/pages/Home.tsx        — головна сторінка, логіка фільтрів
src/sections/             — таблиця, фільтри, панель порівняння, довідник
GLOSSARY.md               — пояснення термінів (хмара, коробка, Enterprise…)
.github/workflows/        — автодеплой на GitHub Pages
```

Пояснення всіх термінів: [GLOSSARY.md](./GLOSSARY.md).
