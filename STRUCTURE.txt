СТРУКТУРА ПРОЕКТУ «CRM-Каталог»
================================
Односторінковий сайт-агрегатор українських CRM-систем (React + TypeScript + Vite + Tailwind CSS).
Бекенду немає: усі дані лежать у src/data/crms.ts, сайт публікується на GitHub Pages.

КОРІНЬ ПРОЄКТУ
--------------
index.html            Єдина HTML-сторінка: заголовок, іконка вкладки, точка входу для React.
package.json          Список бібліотек і команд (npm run dev / build / preview).
package-lock.json     Точні версії встановлених бібліотек (генерується автоматично).
vite.config.ts        Налаштування збірки Vite (шляхи, псевдонім @ -> src).
tailwind.config.js    Налаштування Tailwind: кольори, темна тема (клас .dark).
postcss.config.js     Підключення Tailwind до CSS.
tsconfig.json         Головний конфіг TypeScript (посилається на два файли нижче).
tsconfig.app.json     Правила TypeScript для коду сайту (папка src).
tsconfig.node.json    Правила TypeScript для конфігів збірки (vite.config.ts).
eslint.config.js      Правила перевірки стилю коду.
components.json       Налаштування шаблону shadcn/ui (для роботи сайту не потрібен).
.gitignore            Які файли Git не завантажує (node_modules, dist).
README.md             Короткий опис, запуск, публікація.
GLOSSARY.md           Пояснення термінів: хмара, коробка, Enterprise, B2B тощо.
STRUCTURE.txt         Цей файл.
public/ (або images.jpg)  Іконка вкладки браузера (favicon).

.github/workflows/
  deploy.yml          Автоматична збірка і публікація сайту на GitHub Pages після кожного push у main.

src/ — ВЕСЬ КОД САЙТУ
---------------------
main.tsx              Точка входу: запускає React, підключає маршрутизацію (HashRouter).
App.tsx               Маршрути сторінок (зараз одна — Home).
App.css               Порожній/зайвий стильовий файл із шаблону.
index.css             Глобальні стилі: шрифти, світла і темна палітра, класи .btn-outline, .tag-chip, .label-caps.

src/data/
  crms.ts             ДАНІ: тип Crm, списки фільтрів (SEGMENTS, FEATURE_TAGS), підписи типів і масив CRMS з усіма системами. Щоб додати CRM для всіх — дописати об'єкт сюди.

src/pages/
  Home.tsx            Головна (і єдина) сторінка: шапка, пошук, стан фільтрів і сортування, порівняння, власні CRM з localStorage.

src/sections/         Блоки сторінки
  FilterPanel.tsx     Ліва панель фільтрів («Для кого», «Тип рішення», «Можливості»).
  CrmTable.tsx        Таблиця CRM: рядки, ціновий рівень, теги, розкриття з плюсами/мінусами/інтеграціями.
  CompareTray.tsx     Панель порівняння до 4 вибраних систем.
  Glossary.tsx        Розкривний довідник термінів унизу сторінки.
  ThemeToggle.tsx     Кнопка перемикання світлої/темної теми (запам'ятовується в браузері).
  AddCrmDialog.tsx    Форма додавання CRM: зберегти у себе (localStorage) або надіслати пропозицію на GitHub (Issue).

src/lib/
  utils.ts            Функція cn() для склеювання CSS-класів (із шаблону, не використовується).

src/hooks/
  use-mobile.ts       Хук визначення мобільного екрана (із шаблону, не використовується).

src/components/ui/    53 готові компоненти shadcn/ui (кнопки, діалоги, календар...). Згенеровані шаблоном і на сайті НЕ використовуються — можна видалити без наслідків.

ПЕРЕВІРЕНІ ПРОПОЗИЦІЇ ВІД КОРИСТУВАЧІВ
--------------------------------------
Кнопка «+ Додати CRM» -> «Надіслати пропозицію на GitHub» створює Issue з готовим об'єктом.
Щоб додати її в каталог: скопіювати блок ```ts з Issue і вставити в масив CRMS у src/data/crms.ts.
